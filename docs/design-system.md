# Design System

## Direction visuelle

Style premium, moderne, technique et sobre.

## Intention

- fond sombre profond ;
- surfaces élégantes ;
- contrastes nets ;
- accents lumineux subtils ;
- typographie forte ;
- beaucoup d'espace ;
- animations fluides et utiles.

## À éviter

- look gaming ;
- surcharge d'effets ;
- templates génériques ;
- barres de compétences artificielles ;
- animations qui nuisent à la lisibilité.

## Composants prioritaires

- Navbar
- Hero
- KPI cards
- Experience timeline
- Project cards
- Skills clusters
- Resume viewer
- Contact panel
- Command palette
- Language switcher

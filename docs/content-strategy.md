# Content Strategy

## Règle principale

Le portfolio doit contenir uniquement des informations professionnelles validées.

## Expériences

Pour chaque expérience :

- entreprise ;
- période ;
- contexte ;
- rôle ;
- responsabilités ;
- outils ;
- résultats ;
- éléments publiables.

## Projets

Pour chaque projet :

- problème ;
- solution ;
- contribution ;
- stack ;
- résultat ;
- démonstration éventuelle.

## Confidentialité

Aucune information client sensible ou confidentielle ne doit être exposée.

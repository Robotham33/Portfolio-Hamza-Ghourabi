# Portfolio — Hamza GHOURABI

Portfolio professionnel de Hamza GHOURABI, centré sur la validation logicielle, l’intégration, la QA et l’automatisation des tests.

## Positionnement

Le portfolio présente un profil d’ingénieur logiciel orienté qualité, avec une expérience construite autour de quatre axes principaux :

- validation & QA ;
- automatisation des tests ;
- intégration & CI/CD ;
- qualité, traçabilité et environnements normés.

Les expériences couvrent notamment les systèmes embarqués, les logiciels complexes et les parcours end-to-end, avec une pratique d’outils tels que Python, Robot Framework, Playwright, Jenkins, TeamCity, DOORS et SIL.

## Environnements

Deux environnements métier structurent le parcours :

- Médical — validation, intégration, traçabilité et environnement qualité lié à l’ISO 13485 ;
- Automobile — validation système, SIL, CI/CD, traçabilité et référentiel ISO 26262.

Les normes sont présentées comme des référentiels et contextes qualité rencontrés dans le parcours, et non comme des certifications personnelles.

## Projets personnels

Le portfolio présente également des projets personnels servant de terrain d’expérimentation produit, web et automatisation, notamment :

## SEO et visibilité

Le site intègre :

- `robots.txt` ;

## Qualité

Le projet utilise une pipeline GitHub Actions exécutant :

- typecheck ;
- lint ;
- Prettier ;
- build Next.js.

Les changements sont préparés sur des branches dédiées, vérifiés via une preview Vercel, puis mergés sur `master` après validation.
